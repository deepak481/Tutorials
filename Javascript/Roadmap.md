# 30-Day JavaScript Bootcamp: Zero to MAANG

## The Roadmap

Here's your complete 30-day plan, Deepak. Each day builds on the previous one.

**Week 1 — The Language Foundation**
- Day 1: What is JavaScript, how engines work, variables (`let`, `const`, `var`), data types, type system
- Day 2: Operators, type coercion, comparisons (`==` vs `===`), truthy/falsy
- Day 3: Control flow — `if/else`, `switch`, loops (`for`, `while`, `for...of`, `for...in`)
- Day 4: Functions — declarations, expressions, arrow functions, parameters, return values
- Day 5: **Revision + Project** — Build a CLI quiz game using everything from Days 1–4

**Week 2 — Objects, Arrays & How JS Runs**
- Day 6: Objects — creation, access, methods, `this` keyword intro
- Day 7: Arrays — methods deep dive (map, filter, reduce, etc.)
- Day 8: Execution context, call stack, hoisting, scope chain, lexical environment
- Day 9: Closures — the most important concept in JS
- Day 10: **MAANG Mock Interview #1** — Theory + coding (scope, closures, hoisting)

**Week 3 — Prototypes, Classes & Async**
- Day 11: Prototypes, prototype chain, `__proto__` vs `.prototype`
- Day 12: `this` keyword deep dive — all 5 binding rules
- Day 13: Classes, `new` keyword, inheritance, `super`
- Day 14: Callbacks, event loop, microtask vs macrotask queues
- Day 15: **Revision + Project** — Build an async task scheduler

**Week 4 — Async Mastery & Advanced Patterns**
- Day 16: Promises — construction, chaining, error handling
- Day 17: `async/await`, error patterns, parallel execution
- Day 18: Iterators, generators, `Symbol.iterator`
- Day 19: Modules — CommonJS vs ES Modules, import/export, tree shaking
- Day 20: **MAANG Mock Interview #2** — Promises, event loop, prototypes

**Week 5 — Pro-Level JavaScript**
- Day 21: Error handling patterns, custom errors, defensive coding
- Day 22: `Map`, `Set`, `WeakMap`, `WeakRef`, garbage collection
- Day 23: Proxy, Reflect, metaprogramming
- Day 24: Regular expressions, string internals, tagged templates
- Day 25: **Revision + Project** — Build a reactive state management library

**Week 6 — Interview Mastery**
- Day 26: Polyfills — `bind`, `call`, `apply`, `Promise.all`, `debounce`, `throttle`
- Day 27: Design patterns — Module, Observer, Pub/Sub, Factory, Singleton
- Day 28: Performance — memory leaks, V8 optimizations, hidden classes, inline caches
- Day 29: Frontend system design thinking — event delegation, virtual lists, web workers
- Day 30: **Final MAANG Mock Interview** — Full round simulation
