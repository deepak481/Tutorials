# 30-Day React Mastery Bootcamp — Roadmap

**Week 1: Foundations**
- Day 1: What is React? Why it exists. JSX from first principles. Your first component.
- Day 2: Components deep dive — functional components, component trees, composition vs inheritance.
- Day 3: Props — data flow, children, destructuring, prop types, one-way data flow.
- Day 4: State — useState, how React re-renders, state vs props, batching.
- Day 5: **Revision + Mini Project: Interactive Profile Card Builder**

**Week 2: Hooks & Interactivity**
- Day 6: Event handling, synthetic events, forms (controlled vs uncontrolled).
- Day 7: useEffect — side effects, cleanup, dependency arrays, common pitfalls.
- Day 8: useRef, DOM access, uncontrolled inputs, forwarding refs.
- Day 9: Conditional rendering, lists & keys, reconciliation algorithm.
- Day 10: **MAANG Mock Interview #1 + Machine Coding: Todo App with filters**

**Week 3: Architecture & Patterns**
- Day 11: Custom Hooks — extracting logic, reusable patterns.
- Day 12: Context API — prop drilling problem, createContext, useContext.
- Day 13: useReducer — complex state, reducer pattern, Context + Reducer.
- Day 14: React Router — SPA routing, nested routes, dynamic params, protected routes.
- Day 15: **Revision + Machine Coding: Multi-page Notes App with routing**

**Week 4: State Management & Data**
- Day 16: Redux Toolkit — store, slices, dispatch, selectors, middleware basics.
- Day 17: Zustand & state management comparison. When to use what.
- Day 18: API integration — fetch, async patterns, loading/error states, custom hooks.
- Day 19: TanStack Query — caching, stale time, mutations, infinite queries.
- Day 20: **MAANG Mock Interview #2 + Machine Coding: Autocomplete/Typeahead with debounce**

**Week 5: Performance & Internals**
- Day 21: React internals — Virtual DOM, concurrent rendering, Fiber architecture, reconciliation, commit phases.
- Day 22: Performance — React.memo, useMemo, useCallback, when to optimize.
- Day 23: Code splitting, lazy loading, Suspense, Error Boundaries.
- Day 24: Accessibility (a11y), semantic HTML in React, ARIA, keyboard nav.
- Day 25: **Revision + Machine Coding: Infinite Scroll Data Table**

**Week 6: Production & Interview Mastery**
- Day 26: Testing — Jest, React Testing Library, unit/integration tests.
- Day 27: Security in React — XSS, sanitization, CSP. Advanced patterns (compound components, render props, HOCs).
- Day 28: Machine Coding marathon — File Explorer (recursive), Nested Comments, Kanban Board.
- Day 29: Machine Coding marathon — E-commerce product page, Dashboard with charts.
- Day 30: **Final MAANG Mock Interview — Full simulation + Personalized Senior/Staff roadmap**
